# Idle Alert Exclusions

RimWorld 1.6 and 1.7 mod. Adds a checkbox column to the Assign tab; unchecked colonists are left out of the "colonists idle" alert. Everyone is counted by default.

## Install (recommended)

1. Subscribe to [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) on the Steam Workshop.
2. Subscribe to [Idle Alert Exclusions](https://steamcommunity.com/sharedfiles/filedetails/?id=PUBLISHED_FILE_ID) on the Steam Workshop.
2. Launch RimWorld, open the Mods menu, and enable both, with Harmony above Idle Alert Exclusions.
3. Restart when prompted.

Safe to add to or remove from an existing save. Should support mods that modify the Assign Tab; I attempt to append to the end of the columns and should support modded columns.

## Install (manual)

Copy this folder to `<Steam>/RimWorld/Mods/`. Enable it after Harmony.
